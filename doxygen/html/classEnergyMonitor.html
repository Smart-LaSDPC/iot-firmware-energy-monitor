Descrição detalhada

Lê o INA226 periodicamente em uma task de prioridade 1 e acumula as medidas da janela atual, que vai do último reset até a leitura.

Os acumuladores ficam na memória RTC, então a janela sobrevive ao deep sleep. Por isso só uma instância deve existir: todas compartilham os mesmos acumuladores.

◆ begin()

bool EnergyMonitor::begin ( )

Inicia o barramento I2C, configura o INA226 e cria o mutex e a task de medição.

Pode ser chamado de novo após uma falha: o que já foi criado é reaproveitado.

Retorna
true se a inicialização foi concluída; false se o barramento ou o sensor não responderam, ou se faltou memória para o mutex ou para a task.
